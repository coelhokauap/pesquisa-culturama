## Description

**Pesquisa Culturama** is a web application designed to collect user feedback about cultural events and experiences offered by the fictional company **Culturama**.

The project provides a **simple and interactive survey interface**, allowing users to share their opinions about events, preferences, and overall satisfaction.

The application focuses on **clarity, accessibility, and responsive design**, ensuring that the survey can be easily completed on different devices such as desktops, tablets, and smartphones.

---

## Project Objective

The goal of **Pesquisa Culturama** is to create a **user-friendly survey platform** that allows users to:

- Provide feedback about cultural events
- Share their preferences and experiences
- Interact with a simple and intuitive interface
- Demonstrate practical front-end development concepts

## Features

- Interactive survey form
- Responsive layout for multiple devices
- Clean and intuitive user interface
- Lightweight and fast web page
